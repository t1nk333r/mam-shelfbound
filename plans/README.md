## Findings considered and rejected

- **No authentication on the app**: intentional and documented (`README.md:64`
  — "The app has no authentication, so do not expose it directly to the public
  internet"). Not a defect. Offered instead as a *direction* option (optional
  env-gated auth token) for the maintainer to weigh — not turned into a fix plan.
- **Single-file 905-line `main.py`**: `AGENTS.md:26` explicitly prefers flat
  helpers in `main.py` over new packages. By-design; not debt to "fix" (targeted
  extraction for testability is noted as deferred follow-up inside plan 001).
- **Freeleech wedges limited to audiobooks**: intentional (commit `92c95a3`
  "Limit FL wedges to audiobooks"). Not a bug.
- **SQL injection / XSS**: not found. All SQL uses SQLAlchemy bound parameters;
  the frontend escapes text sinks via `escapeHtml` and URL-encodes link IDs. The
  one latent note — `escapeHtml` (`app/static/app.js:187`) doesn't escape quotes
  — is not currently reachable (escaped values render in text context, not
  attributes); not worth a plan today, but worth remembering before putting any
  escaped value into an HTML attribute.
